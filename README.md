# Car Rental System – UML Project

Project by: A team of 3 students during our exchange semester at the University of California, Irvine (UCI)


 Project Overview
This project is a conceptual design of a Car Rental System, developed for our Object-Oriented Analysis & Design course using UML. The goal was to model and analyze the core functionalities of a rental service using various Unified Modeling Language (UML) diagrams and best practices in software design.

# Use Case Summary
The system supports the following primary functionalities:

Add & View Customers: Register new customers and display customer information.

Rent a Car: Allow customers to rent available vehicles.

Rental Management: Keep track of rental records, durations, and returns.

Car & Customer Management: View, update, or delete records of cars and customers.

Improvement Suggestions: Discussed possible future extensions like online payment integration, loyalty programs, and automatic notifications.

# UML Diagrams Included
Use Case Diagram – Identifies key actors (e.g., Admin, Customer) and their interactions with the system.

Class Diagram – Defines the core classes (Car, Customer, Rental) and their relationships, attributes, and methods.

Sequence Diagram – Illustrates the step-by-step interaction between objects during the "Rent a Car" process.

Object Diagram – Provides a snapshot of system objects and their relationships at a particular time.

#Key Concepts Applied
Encapsulation and modular class design

Actor-System interaction modeling

Sequence-based behavioral representation

Static vs. dynamic views of system architecture

#Possible Improvements

#Final Thoughts
This project helped us solidify our understanding of UML by applying it to a real-world scenario. It allowed us to practice designing robust, scalable systems with clear structure and logic. Working as a team also emphasized the importance of collaboration in software analysis and planning.
